GLightbox works with plain HTML or JavaScript and supports touch, keyboard navigation, image zoom, and video playback.

## What you can build

- Image galleries with responsive sources and descriptions
- YouTube, Vimeo, and self-hosted video slides
- Iframes and inline HTML content
- Custom animations, themes, and player settings

See the [interactive demo](/glightbox/demo.html) or start with the [installation guide](/glightbox/getting-started/).
